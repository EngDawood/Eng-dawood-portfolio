# Academic Excellence Hub – Next.js Academic Services Platform

Welcome to **Academic Excellence Hub** (مركز التميز الأكاديمي), a comprehensive academic services platform built with Next.js. This project was transformed from a personal developer portfolio into a bilingual (Arabic/English) academic services website, targeting Arabic-speaking students globally.

## 🎯 Core Features

- **Academic Data Architecture:**  
  - Modular TypeScript interfaces for academic services ([src/data/academic-types.ts](src/data/academic-types.ts))
  - Bilingual academic data ([src/data/academic-data.ts](src/data/academic-data.ts))
  - Academic Excellence Hub profile ([src/data/me.ts](src/data/me.ts))

- **Academic Specializations:**  
  1. Computer Science & Programming (علوم الحاسب والبرمجة)
  2. Engineering Services (الخدمات الهندسية)
  3. Medical & Health Sciences (العلوم الطبية والصحية)
  4. Natural Sciences & Mathematics (العلوم الطبيعية والرياضيات)
  5. Business & Economics (إدارة الأعمال والاقتصاد)
  6. Humanities & Social Sciences (العلوم الإنسانية والاجتماعية)

- **Student Success & Testimonials:**  
  - 2,847+ students served
  - 3,920+ academic projects completed
  - Professional testimonials from major universities

- **Academic Credentials:**  
  - Academic certifications and accreditations
  - University-focused project portfolio
  - Student success statistics
